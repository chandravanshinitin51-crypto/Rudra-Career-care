# Rudra Career Care Website

A professional mobile-friendly admissions website with a browser-based admin panel demo.

## Files
- `public/index.html` — public website
- `public/admin.html` — admin panel

## Important
This version stores website edits and enquiries in the browser's localStorage. It is suitable as a working prototype/demo, but it is NOT a production multi-user backend.

For a production launch, connect the admin panel to a real database/auth system (e.g. Supabase/PostgreSQL) and deploy it with HTTPS.
